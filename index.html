Bash Commands I have learnt

1. touch

File Creation

The touch commands creates a new, empty file. If already exists, it simply updates the file's last-modified timestamp instead of changing its content. Its one of the simplest ways to create a file directly from the terminal.

Syntax: touch filename

Example: touch notes.txt

Output:(no output - the file notes.txt is silently created in the current folder)

2. mkdir

Folder Creation

The mkdir creates a new, empty folder(directory) at the location you specify

Syntax: mkdir foldername

Example: mkdir project

Output: (no output - the folder project is created in the current directory)

3. cd

Change Directory

the cd command changes the current working directory, moving you into a different folder in the terminal

Syntax:cd foldername

Example: cd project

Output: prompt changes to show you arer now inside ~/project
